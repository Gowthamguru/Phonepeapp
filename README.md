<h1>PhonePe Pulse Data Visualization Project</h1>
With the rise of digital payments in India, platforms like PhonePe play a major role in transforming financial behaviour. 
This project aims to explore, analyse, and visualize aggregated transaction data from PhonePe Pulse to uncover meaningful insights about user engagement, service adoption, and regional trends.

<h1>Project Objectives</h1>
-	Analyse UPI transaction trends using PhonePe Pulse data <br/>
-	Visualize transaction values across states, districts, and pin codes <br/>
-	Identify top-performing locations and most-used service categories <br/>
-	Build an interactive dashboard to explore data dynamically <br/>
-	Support strategic decision-making for stakeholders through insights <br/>
<h1>Features & Visualizations
</h1>
•	Year-wise and quarter-wise transaction trend analysis <br/>
•	State and district-level choropleth maps <br/>
•	Pie and bar charts for category-wise usage <br/>
•	Line graphs for temporal analysis <br/>
•	Interactive filters: Year, State, Quarter <br/>
